# Ciel et irradiance solaire — Streamlit

Application autonome présentant six séquences d'images du ciel synchronisées avec l'irradiance solaire globale et diffuse.

## Lancer localement

```bash
streamlit run app.py
```

## Déployer sur Streamlit Community Cloud

1. Publier ce dossier dans un dépôt GitHub.
2. Dans Streamlit Community Cloud, créer une application depuis ce dépôt.
3. Choisir `app.py` comme fichier principal.
